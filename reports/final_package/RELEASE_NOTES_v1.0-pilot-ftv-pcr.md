# Release Notes: v1.0-pilot-ftv-pcr

## Project title

Pilot FTV-Based Prediction of Pathologic Complete Response in I-SPY2 Breast MRI with Tumor-Source Validation and a Future Temporal Graph Learning Framework

## Final current result

- Main pilot model: Phase 8C FTV support-data SVM_RBF
- AUROC: 0.6667
- AUPRC: 0.7528
- Brier score: 0.2405

## Final decision

The FTV support-data model is the main current result. Temporal GNN is future work because the graph-ready dataset is too small and the temporal-delta model did not beat the FTV model.

## Important limitation

This is a pilot feasibility study, not clinical validation.
